# My Seaside Diary

A cozy, Hometown Cha-Cha-Cha inspired personal blog. Single static page, no build step.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (e.g. `my-seaside-diary`).
2. Upload `index.html` and `README.md` (drag and drop works).
3. Go to Settings > Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Notes
- Your photo, name, intro and post text are saved in each visitor's own browser (localStorage), so they are not shared between devices.
- To change section names, icons or colours, edit the `S` and `T` arrays near the bottom of `index.html`.
